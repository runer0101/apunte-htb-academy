Sección 12 Wireshark Advanced Usage

Dos plugins para dos preguntas

Statistics resume la captura sin perder el contexto: conversaciones, endpoints, top talkers y distribución por dirección IP o protocolo. Analyze contiene herramientas para trabajar con lo que ya identificaste: display filters, seguimiento de streams y Expert Information, que agrupa advertencias y errores.

01

Statistics → Conversations. Compara bytes, paquetes, duración y extremos de cada conversación.

02

Statistics → Endpoints / Protocol Hierarchy. Encuentra top talkers y el porcentaje de cada protocolo.

03

Analyze. Reduce la vista, sigue el stream correcto y revisa Expert Info sin confundir una alerta con una conclusión.

01-statistics
analyst@lab:~$ tshark -r case.pcapng -q -z conv,ip -z endpoints,ip -z io,phsConversations / Endpoints / Protocol Hierarchy Statistics10.10.14.23 ↔ 198.51.100.20 · TCP · 84 kB

Statistics: metadatos y top talkers

Abre Statistics → Conversations para ver qué pares hablaron, cuántos paquetes intercambiaron y cuánto duró la conversación. En Statistics → Endpoints, ordena por paquetes o bytes para encontrar los top talkers. Statistics → Protocol Hierarchy desglosa el porcentaje de tráfico IP, TCP, UDP y protocolos de aplicación. Estos números describen la captura; no prueban por sí solos que exista una intrusión.

02-top-talkers
analyst@lab:~$ tshark -r case.pcapng -q -z endpoints,ip198.51.100.20 1240 packets 1.8 MB10.10.14.23 1187 packets 1.5 MB

Analyze: filtros y Expert Info

Un display filter como ip.addr == 10.10.14.23 and tcp solo cambia la vista, no la evidencia guardada. Desde Analyze → Follow puedes seguir una conversación y, en Analyze → Expert Information, revisar retransmisiones, segmentos fuera de orden o problemas de protocolo. Lee cada indicador en su contexto y conserva el PCAP original.

03-analyze
analyst@lab:~$ tshark -r case.pcapng -Y 'ip.addr == 10.10.14.23 and tcp' -c 312 10.10.14.23 → 198.51.100.20 TCPExpert: retransmission (requires context)

Follow TCP Stream

Selecciona un segmento TCP y usa Analyze → Follow → TCP Stream para reconstruir el intercambio en orden. Wireshark asigna un número a cada conversación; el filtro tcp.stream eq 3 deja visibles solo sus paquetes. Cambiar el filtro no descifra TLS ni convierte bytes binarios en texto legible.

04-follow-stream
analyst@lab:~$ tshark -r case.pcapng -Y 'tcp.stream eq 3' -T fields -e tcp.stream3Follow TCP Stream: client ↔ server (stream 3)

Exportar objetos y trabajar con FTP

Con una captura autorizada, usa File → Export → Objects → y el protocolo que Wireshark haya identificado (por ejemplo HTTP o FTP-DATA). Guarda los objetos en un directorio de análisis, no sobre el PCAP. En FTP, el puerto 21 suele transportar el canal de control (comandos y respuestas); el puerto 20 es el canal de datos del modo activo, aunque el modo pasivo negocia otro puerto de datos. Por eso control y datos deben analizarse por separado.

FiltroQué muestra
ftpComandos y respuestas del canal de control FTP.
ftp.request.commandCampo del comando solicitado, útil para localizar USER, RETR, STOR o LIST.
ftp-dataCanal que transporta el contenido de archivos o listados.
05-ftp-safe-workflow
analyst@lab:~$ tshark -r authorized-ftp.pcapng -Y 'ftp or ftp-data' -T fields -e tcp.stream -e _ws.col.Info4 USER analyst4 RETR report.pdf5 ftp-data · exported object: report.pdf

Procedimiento seguro: confirma autorización y alcance; trabaja sobre una copia de la captura; identifica primero el stream de control con ftp y ftp.request.command; relaciona el stream de datos con ftp-data; exporta desde el menú; calcula un hash y usa file o una cabecera mágica para validar el tipo. No ejecutes el archivo extraído y redacta credenciales o datos personales del informe.

Cómo usar estas tarjetas: intenta responder en inglés, oculta la respuesta mentalmente y después copia solo el valor exacto.
Q1

Which plugin tab can provide us with a way to view conversation metadata and even protocol breakdowns for the entire PCAP file?

¿Qué pestaña de plugins permite ver los metadatos de las conversaciones e incluso el desglose de protocolos de todo el archivo PCAP?

RespuestaStatistics
Por qué
Statistics resume conversaciones, endpoints y jerarquía de protocolos de toda la captura; Analyze contiene las herramientas de análisis interactivo.
q1
analyst@lab:~$ wireshark case.pcapngStatistics → Conversations / Endpoints / Protocol Hierarchy
Q2

What plugin tab will allow me to accomplish tasks such as applying filters, following streams, and viewing expert info?

¿Qué pestaña de plugins permite aplicar filtros, seguir streams y consultar la información de experto?

RespuestaAnalyze
Por qué
Analyze reúne el filtrado y las herramientas para seguir y diagnosticar conversaciones.
q2
analyst@lab:~$ tshark -r case.pcapng -Y 'tcp.stream eq 3'Analyze → Follow → TCP Stream
Q3

What stream oriented Transport protocol enables us to follow and rebuild conversations and the included data?

¿Qué protocolo de transporte orientado a streams permite seguir y reconstruir las conversaciones y sus datos?

RespuestaTCP
Por qué
TCP mantiene una conversación orientada a conexión y permite reordenar sus segmentos; seguir el stream TCP correcto ayuda a reconstruir los datos transferidos.
q3
analyst@lab:~$ tcp.stream eq 3TCP stream selected for reconstruction
Q4

True or False: Wireshark can extract files from HTTP traffic.

Verdadero o falso: Wireshark puede extraer archivos del tráfico HTTP.

RespuestaTrue
Por qué
Wireshark puede exportar objetos HTTP reensamblados desde una captura completa mediante File → Export → Objects → HTTP.
q4
analyst@lab:~$ file exported-objectHTTP object reconstructed successfully
Q5

True or False: The ftp-data filter will show us any data sent over TCP port 21.

Verdadero o falso: el filtro ftp-data mostrará cualquier dato enviado por el puerto TCP 21.

RespuestaFalse
Por qué
ftp-data muestra el canal de datos, no TCP/21, que es el canal de control. Usa ftp para comandos y respuestas y ftp-data para el contenido transferido.
q5
analyst@lab:~$ tshark -r authorized-ftp.pcapng -Y ftp-dataData channel only; FTP control remains filtered by ftp
