Sección 10 Analysis with Wireshark

¿Qué es Wireshark?

Wireshark es un analizador gráfico y gratuito de protocolos de red. Abre capturas en formatos como PCAP/PCAPNG, decodifica sus capas y permite examinar paquetes en tiempo real o después de una captura.

01

Capturar. Obtén paquetes desde una interfaz de red, si tienes permisos.

02

Decodificar. Reconoce cientos de protocolos y muestra sus campos.

03

Investigar. Filtra, sigue conversaciones, exporta evidencia y busca anomalías.

!Autorización: captura únicamente tráfico de redes y sistemas que puedas monitorizar legalmente. Un filtro no cambia ese requisito.

Capacidades y requisitos

Además de mostrar paquetes, Wireshark puede seguir streams TCP/UDP, reconstruir protocolos, aplicar estadísticas, colorear tráfico, resolver nombres y exportar objetos o paquetes seleccionados.

NecesitasResumen
SistemaWindows, macOS o una distribución Linux compatible.
PermisosPrivilegios para capturar desde la interfaz; leer un PCAP existente normalmente no los requiere.
FuenteUna interfaz activa o un archivo PCAP/PCAPNG autorizado.
RecursosEspacio para guardar capturas y memoria suficiente para abrir archivos grandes.

En Linux, instala desde los repositorios de tu distribución:

install-linux
analyst@lab:~$ sudo apt update && sudo apt install wireshark tsharkWireshark/TShark installed successfully

Durante la instalación de Debian/Ubuntu, permite la captura para usuarios no root si corresponde y añade tu cuenta al grupo wireshark; cierra sesión y vuelve a entrar para que el cambio tenga efecto.

Wireshark, TShark y Termshark

Son tres formas de trabajar con el mismo ecosistema de análisis: elige la interfaz según el entorno y la tarea.

HerramientaInterfazCuándo usarla
WiresharkGráficaExploración visual profunda, paneles, estadísticas y seguimiento de streams.
TSharkLínea de comandosServidores sin escritorio, automatización, scripts y extracción rápida de campos.
TermsharkTUI en terminalUna experiencia interactiva parecida a Wireshark cuando solo hay terminal.

TShark: switches esenciales

TShark comparte muchos decodificadores con Wireshark. Esta tabla resume los switches del material; combina opciones y comillas con cuidado en tu shell.

SwitchFunciónEjemplo
-DLista las interfaces disponibles.tshark -D
-LLista los tipos de enlace de una interfaz.tshark -L -i eth0
-iSelecciona la interfaz de captura.tshark -i 2
-fAplica un filtro de captura BPF.-f "port 53"
-cDetiene la captura después de N paquetes.-c 10
-aUsa una condición de parada automática (por ejemplo, duración).-a duration:30
-rLee paquetes desde un archivo.-r traffic.pcap
-w / -W-w escribe la captura; -W especifica el formato de archivo al escribir, según el material.-w out.pcapng -W pcapng
-PImprime el resumen de cada paquete.-P
-xMuestra bytes en hexadecimal y ASCII.-x
-hMuestra la ayuda.tshark -h

Ejemplos de terminal

Los filtros de captura van con -f; los filtros de visualización, con -Y. Para leer un archivo usa -r.

tshark-cheatsheet
analyst@lab:~$ tshark -D1. eth02. anyanalyst@lab:~$ sudo tshark -i 1 -f "port 53" -c 5 -w dns.pcapngCapturing on 'eth0'analyst@lab:~$ tshark -r dns.pcapng -Y "dns" -P1 0.000000 10.10.10.5 → 10.10.10.1 DNS 74 Standard queryanalyst@lab:~$ tshark -r dns.pcapng -Y "tcp.port == 80" -x0000 45 00 00 34 ... E..4

El último comando combina lectura, display filter y la vista hexadecimal/ASCII. En Wireshark, el equivalente del filtro es escribirlo en la barra de display filter.

Los tres paneles de Wireshark

PanelQué muestraUso
Packet ListUna fila por paquete: número, tiempo, origen, destino, protocolo, longitud e información.Seleccionar rápidamente el paquete y ordenar la captura.
Packet DetailsÁrbol expandible con las capas y campos decodificados.Inspeccionar cabeceras, flags, puertos y valores concretos.
Packet BytesBytes crudos del paquete en hexadecimal y ASCII.Corroborar la decodificación y encontrar datos visibles en la carga.

Al seleccionar una fila del Packet List, los otros dos paneles se actualizan para ese mismo paquete. Expandir una capa en Packet Details resalta sus bytes correspondientes en Packet Bytes.

Capture filters frente a display filters

No son intercambiables: uno decide qué se guarda y el otro qué se muestra.

TipoSintaxisMomentoEjemplo
Capture filterBPFDurante la captura; descarta lo que no coincide.port 443
Display filterWiresharkAl mostrar o leer; oculta temporalmente lo que no coincide.tcp.port == 443
filters
analyst@lab:~$ sudo tshark -i eth0 -f "host 10.10.10.5" -w host.pcapnganalyst@lab:~$ tshark -r host.pcapng -Y 'http.request' -P1 0.000000 HTTP GET /index.html
!Importante: un display filter no modifica el PCAP. Solo cambia los paquetes visibles en la interfaz; puedes quitarlo o cambiarlo y recuperar la vista completa. Un capture filter sí puede impedir que ciertos paquetes lleguen a la captura guardada.

Preguntas de comprobación

Conserva la pregunta original en inglés y usa la traducción para comprobar tu comprensión.

Q1

True or False: Wireshark can run on both Windows and Linux.

¿Verdadero o falso? Wireshark puede ejecutarse tanto en Windows como en Linux.

RespuestaTrue
Por qué
Wireshark es multiplataforma y ofrece versiones para Windows y Linux, entre otros sistemas.

analyst@lab:~$ which wireshark/usr/bin/wiresharkTambién está disponible en Windows.
Q2

Which Wireshark pane lists captured packets in rows?

¿Qué panel de Wireshark enumera los paquetes capturados en filas?

RespuestaPacket List
Por qué
Packet List presenta una fila por paquete y sus columnas de resumen.

RespuestaPacket Bytes

Which TShark switch lists the available interfaces?

Q5

Which switch applies a capture filter in TShark?

¿Qué switch aplica un filtro de captura en TShark?

Respuesta-f
Por qué
-f recibe una expresión BPF antes de guardar los paquetes.

Q6

Is a capture filter applied before the capture starts or after? (answer before or after)

¿Un filtro de captura se aplica antes de que empiece la captura o después? (responde before o after).

Respuestabefore
Por qué
El capture filter se configura antes de iniciar la captura y descarta los paquetes que no coinciden, por ejemplo con -f "port 53".
